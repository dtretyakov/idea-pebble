Reports mistakes in the pebble section of package.json that pebble-tool would otherwise report only when building, or not at all:
  • a targetPlatforms entry that is not a Pebble platform;
  • an Alloy project targeting a platform Alloy does not run on — only emery and gabbro;
  • a projectType pebble-tool cannot build;
  • a resources.media entry whose file is not in resources/, either as named or as a platform variant like logo~color.png — the build fails with a Python traceback;
  • a message key that no source in src/ or worker_src/ mentions, as MESSAGE_KEY_name in C or as the name itself in JavaScript and Clay's configuration.
