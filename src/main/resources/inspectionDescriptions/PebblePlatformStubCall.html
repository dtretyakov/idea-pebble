Reports calls in C to SDK functions that some of the project's targetPlatforms only stub out.

Each platform's pebble.h declares the whole API. What a watch lacks — the speaker, touch, the RGB backlight on the older platforms — is a macro there that ignores its arguments, such as #define speaker_play_notes(...) (0). The call compiles for every platform and does nothing on those.

A call is not reported where a PBL_ condition chooses the platforms:

#if defined(PBL_SPEAKER)
  speaker_play_notes(notes, count, 100);
#endif

int width = PBL_IF_ROUND_ELSE(180, 144);

Stubs that return a value of their own, like persist_get_max_size on aplite, are the SDK's answer for that platform and are not reported.
